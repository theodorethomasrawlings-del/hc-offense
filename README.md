# HC Offense

Live offensive possession chart for the bench, on an iPad. Design doc in `docs/2026-11-02-hc-offense-design.md`.

Live: https://theodorethomasrawlings-del.github.io/hc-offense/

## Run on the Mac (dev)

```
npm install
npm run dev        # http://localhost:5173
npm test
npm run build      # static site in dist/
```

## Put it on the iPad

Open the live URL in Safari, Share, **Add to Home Screen**. Open it from the home screen (fullscreen, landscape). Games are stored on the iPad; export from the Summary screen.
